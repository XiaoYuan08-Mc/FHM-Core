# FHM-Core 26.3 26.3-r2

## bug

进服后世界完全不加载，客户端只剩天空和云，日志报 `Timed out while waiting for the client to load chunks`，存档几乎不落区块。

## 修复

`gale-apply.ps1` 生成的 SimulationFlag 垫片默认值是 `false`，而把它翻回 `true` 的投机 tick 补丁（改 `MinecraftServer` 那段）没合进来。结果是 `ServerChunkCache.tick()`、`LevelTicks`、`ActivationRange`、`Entity.tick` 里所有 `if (!SimulationFlag.REAL) return;` 全部提前返回，区块不加载也不发送。垫片默认值改成 `true`，重编。

修复提交 `593187057`。
